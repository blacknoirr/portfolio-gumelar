# Portfolio

A minimalist portfolio website for Gumelar Adi, built with Next.js 14, Tailwind CSS, and TypeScript.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- Next.js 14 (App Router)
- Tailwind CSS 3
- TypeScript
- next/image for image optimization
- next/font for typography
